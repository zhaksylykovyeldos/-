# Информационная система автомойки

## Описание проекта
Данный проект представляет собой информационную систему управления автомойкой.

## Цель проекта
Автоматизация процесса обслуживания клиентов, регистрации автомобилей, управления услугами и заказами.

## Основные сущности
1. Clients — информация о клиентах.
2. Cars — информация об автомобилях.
3. Services — услуги автомойки.
4. Orders — заказы клиентов.

## Используемые технологии
- Python
- Git
- GitHub
- ER-диаграмма
